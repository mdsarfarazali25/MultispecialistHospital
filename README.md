# 🏥 Multispecialist Hospital Website

A responsive hospital website with appointment booking, doctor profiles, and service listings. Built with **HTML, CSS and Bootstrap**.

🔗 **Live Demo:** [https://mdsarfarazali25.github.io/MultispecialistHospital/](https://mdsarfarazali25.github.io/MultispecialistHospital/)

---

## 🌟 Key Features
- **Appointment Booking**: Interactive form for patients to request appointments.
- **Department Pages**: Dedicated sections for specialties (Cardiology, Neurology, etc.).
- **Doctor Profiles**: Details about medical staff with images and qualifications.
- **Emergency Contact**: Quick access to emergency numbers and locations.
- **Responsive Design**: Mobile-friendly layout for all devices.
- **Dynamic UI**: Smooth animations and transitions for better UX.
